# 模式4矩形识别修复（2026-10-29）

本次只调整副本中的 `src/isp/shape_simple_recognizer.v`。模式0～3、上位机协议和中心蓝色引导框接口保持原有配置。

## 修复内容

1. 修正16×16网格的边缘汇聚。旧实现只有行内累积，输出网格时实际保留每块最后一行；新增按块列的跨行累积，网格现在取整块所有像素的逻辑或，避免细横边随所在行位置消失。
2. 包围盒边界统计使用相对宽度的侧边带，避免轻微倾斜后只有个别顶点落在包围盒极值线上。
3. 矩形需得到至少三个角区的支持，每个角区至少两个不同边缘网格，另需满足边界数量条件。角区宽高为包围盒的约1/10，最少保留一格深度，减少粗网格圆形被判成矩形。
4. 矩形优先判定；圆形仍要求包围盒近似方形，且具有支持的角区至多一个。不满足条件输出 UNKNOWN。

这是适用于引导框内单个清晰目标的轻量几何规则识别，不是任意旋转、遮挡和复杂背景下的通用识别器。目标被引导框裁切、框内存在其他明显边缘、目标很小或大幅倾斜时仍可能识别失败。

- 单像素边缘回归：11项，包括四种行位置的矩形、正方形、局部断边、轻微倾斜、圆形和空图。
- 生产参数回归：1920×1080、BLOCK=16、ROI=(560,240)..(1359,839)，检查矩形、倾斜矩形、圆形以及ROI外干扰。
- 原加粗网格测试：矩形和圆形。旧的“圆形”用例实际是一段非对称开口折线，现改为闭合圆环。
- 测试输出见本目录日志。综合、布局布线、时序和发布文件摘要见 `release.json`（构建完成后生成）。
- 新版实板验证待用户进行；仿真通过不代表已完成实板验证。

## 快速上板检查

下载 `bitstreams_analysis/Ti60_Demo_ErosionMulti4_RectFix_20261029.bit`，上位机选择模式4。先将完整、高对比的矩形放在蓝色框中央，四条边都在框内，尽量让目标宽高超过200像素。检查显示 RECT，再换圆形检查 CIRCLE。若失败，先切模式2确认四条边是否清楚、是否被背景干扰，然后返回模式4。

旧 `Ti60_Demo_ErosionMulti4.bit` 保留，便于比较和回退。

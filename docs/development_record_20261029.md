本副本的上位机支持模式0/1/2/3/4。模式3按钮为“多目标几何分析”，模式4按钮为“圆形/矩形识别”。请启动本副本的上位机；其他旧工程的上位机只有模式0～3，不能控制模式4。串口发送 ASCII `4` 后，FPGA 会在视频消隐期间确认并切换到模式4。

模式3下方的“显示 1/2/3 个”按钮发送 ASCII `A/B/C`，只控制 HDMI 上显示的候选框数量，分析器仍然计算并保存最多三个候选。FPGA 在视频消隐期间应用该设置，并通过 `A/B/C` 回传确认；这不会改变候选排序，也不代表只分析一个目标。

模式4是独立的轻量演示识别：它只取中心引导框 `x=560..1359、y=240..839` 内的 Canny 边缘，按 16×16 源像素块压缩成较细粗网格，再依据目标包围盒的长宽关系、四边覆盖和四角占用判断“圆形”“矩形”或“未知”。蓝色引导框和识别掩码使用同一组坐标。矩形优先检查四边覆盖，避免矩形因角点缺失被归为圆形。它不复用模式3的候选排名，也不启用旧的 Hu 识别器；适合单个、清晰、与背景分离的圆形或矩形演示图。该规则分类用于满足简易目标识别展示，不能替代通用目标识别。

## 屏幕字段

示例：`1 E:0002176 W:0120 H:0160 R:01.333 S:000136 OK CAND`

| 字段 | 含义 |
| --- | --- |
| E | 分配到这个连通候选区域的原始 Canny 边缘像素数；每个 4×4 块保留 0..16 的计数，累加时不直接把网格点数乘 16 |
| 彩色框、W、H | 在源图坐标上显示的包围盒及其宽、高；以 4 像素块为精度，可能向外扩展到所在块的边界 |
| R | `max(W,H)/min(W,H)`，不是固定横宽除以竖高；内部输出比值×1000的整数，屏幕显示三位小数；截断取整，最大内部值 65535，即屏幕 65.535 |
| S | 在 480×270 网格上，Moore 外边界遍历的移动次数；对角与水平移动均计一步，含回到起点的最后一步，不遍历内部孔洞 |
| OK / ISO / LIM | 遍历正常结束 / 孤立网格点 / 达到 65536 步上限。OK 不代表原始边缘是物理闭合曲线；开放细线也可能往返遍历后结束 |
| CAND | 连通边缘候选区域。没有新增侵蚀沟语义分类器，不等于已经证明该框是侵蚀沟 |
| `-` / ERR | 对应排名没有候选 / 本批次分析失败。失败批次清除旧框，避免把上一次结果冒充本次结果 |

这里没有沟道面积、实际长度、地面坐标或米/平方米。S 也不能当作沟道中心线长度或精确周长。原图边缘明显的田埂、文字、屏幕边框都可能成为候选，演示时应让输入图尽量占满采集画面。

## 实现结构和限制

`现有流式 Canny → 全幅4×4 OR池化并保留块内边缘计数 → 固定快照 → 行游程/8连通CCL → 按边缘数选前三 → 重放游程生成各目标独立掩码 → 共享Moore轮廓遍历 → 共享移位减法求比值 → 数值转换 → HDMI叠加`

- 模式3不使用旧中心 ROI，不新增 DDR 读写协议；工作快照与目标掩码放在片上 RAM。模式4单独使用文档前述中心引导框。
- 4×4 池化降低分析存储和扫描成本，同时可能把原图距离较近的两条边连为同一候选；原图断裂较大的同一条沟也可能被分成多个候选。
- 采用真正的 8 连通标记及等价集合并，不是按固定画面区域分三组。第二次扫描建立 2 位的目标 ID 掩码，包围盒重叠的目标也分别遍历，不互相混入统计。
- 最多保存 4095 个临时标签，默认筛去总边缘数小于 64 的连通候选。标签耗尽或内部查找异常时整批报错，不静默输出截断结果；后续新帧可恢复。
- 视频数据始终继续流动；分析器忙时整帧跳过，只有空闲后遇到下一帧首个网格才开始新快照。**视频刷新率和统计更新率不同，不承诺逐视频帧完成几何分析。** 快速运动时框可能落后，演示静态图片可先冻结。
- 数值与框作为同一批结果，仅在场消隐更新，防止三条记录分属不同分析帧。统计没有长期目标跟踪功能。
- 长宽比使用 20 周期移位减法实现，没有使用 RTL `/` 运算符生成大型组合除法器；地址运算等仍使用了 4 个 DSP48。

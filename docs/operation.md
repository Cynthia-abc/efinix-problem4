# 操作说明

## 上电与图像确认

使用与原工程一致的 Ti60F225 平台接线，连接 SC2210、DDR3、HDMI 和 USB-UART。下载 `bitstreams/Ti60_Demo_ErosionMulti4_RectFix_20261029.bit`，先在默认模式0检查彩色画面，再连接115200、8N1串口。

## 模式与阈值

上位机发送 ASCII `0`～`4`切换五种模式。模式1观察灰度与白色边缘，模式2观察红色边缘叠加，模式3观察多个候选和几何特征，模式4观察圆形/矩形规则识别。

K1短按增加高阈值8，K2短按减少8。高阈值默认64、范围0～248，低阈值按高阈值的3/8联动，更新在帧边界应用。

## DDR3冻结与回看

双键组合用于冻结/恢复。单键长按阈值为约800 ms：K1发出上一历史帧事件，K2发出下一帧事件；单键长按与短按动作分别处理。帧控制器在冻结回看状态下选择保留的槽位。操作时先冻结，再逐次长按并释放单键回看，最后双键恢复实时显示。

DDR3按四槽循环管理，当前帧及历史帧的可用范围随槽位完成状态变化。图像冻结后，模式3仍可对当前显示图像完成一次分析；框与统计数值在新分析完成后的消隐期间一起更新。

## 模式3演示

使用光照均匀、相互分离且与背景对比明显的合成侵蚀沟样图。尽量让图像占满摄像头画面，减少屏幕边框、文字和环境杂物进入分析范围。上位机“显示1/2/3个”按钮分别发送 `A/B/C`；它控制显示框数，内部仍筛选最多三个候选。

黄色、绿色、青色分别对应当前边缘像素数排名第1、2、3的候选，编号随本次分析排序改变。`E`为边缘像素数，`W/H`为包围盒尺寸，`R`为长边/短边比值，`S`为网格外边界遍历步数。统计是像素域特征，可结合一致采集条件辅助形态对比。

## 模式4演示

将完整、清晰、孤立的圆形或矩形放在中心蓝色引导框内。ROI为800×600，坐标x=560～1359、y=240～839。避免目标裁切、大幅倾斜或明显背景边缘。模式2可先用于检查目标四边是否提取清楚，再切回模式4检查 `CIRCLE`、`RECT` 或 `UNKNOWN`。
